# odm-social-media

Hand-off point for O'Connor Digital Marketing social media files on their way into Publer. Publer copies each file when a post is created, so files here can be removed once the week is scheduled. Nothing here is unpublished work: every file has been approved for posting.

Folders are one per week of the ODM social plan (w01 = 13 to 19 October 2026). Raw file URLs follow the pattern
`https://raw.githubusercontent.com/OConnorDM/odm-social-media/main/w01/<file>`.
